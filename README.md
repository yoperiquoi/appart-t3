# Appartement T3

Rendu 3D interactif (three.js) d'un appartement T3 : état actuel, projet de rénovation, ameublement pièce par pièce et propositions de peinture.

- En ligne : GitHub Pages (voir l'onglet « About » du dépôt).
- En local : `python -m http.server 8000`, puis ouvrir http://localhost:8000.

Tout le rendu tient dans `index.html` ; `src/widget-fragment.html` est le même code sans enveloppe HTML.
